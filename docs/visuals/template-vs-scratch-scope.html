How a Start-from-scratch Rule is configured

Start from scratch is the user-facing route; choosing a start creates a Draft Custom Automation. It becomes Inactive only after the flow is complete and saved but still switched off. A Rule is not just a generic Yes/No label: the user chooses a category, a Rule and any value that Rule needs.

Category → Rule → setting → validation
CategoryRuleUser setsValidation before save or activation
Deal & ownerDeal belongs to this CompanyChoose one Company on this RuleThe current Deal’s owning Company ID must exactly match the selected Company ID. This is per-Rule record data, not Automation-wide scope.
Dates & valueDeal value is above, below or equal to an amountChoose the operator and enter a finite positive amountThe amount must be greater than zero. WeQuote compares it in the Deal Company currency and shows no currency picker.
Dates & valueExpected Close Date is before, on or after a selected dateChoose the comparison and dateA valid date is required.
Dates & valueExpected Close Date is within the next number of daysEnter the number of daysA whole number from 1 to 365 is required.
The saved value must stay visible

The Builder, Map and preview should show the selected Company, amount, date or number of days. They should not replace it with a generic “Saved conditions are met” message. The 12 Templates do not expose this Rule chooser: their Rule and operator stay fixed, except for the two approved High-value thresholds.

Level 3 detail · A New / Custom Pipeline has two separate product cases

Status: review proposal, not confirmed Phase 1. A New / Custom Pipeline is not one more Stage. It adds Pipeline and Stage management, routing, Deal migration, permissions, deletion safeguards and a new compatibility surface.

Case 3A · Another Quote-connected Pipeline

Reuses the seven protected Quote contexts and the same five Custom-Stage gaps. Its count starts with a new seven-context baseline, then adds the rows for every inserted Custom Stage.

Case 3B · Standalone Pipeline

Each user-defined working Stage has 10 Starts (9 shared + Stage entry), 11 Rule families and up to 14 shared Deal Actions. Quote-specific Starts, Rules and Actions are not shown.

Target formula for m working Stages: 10m Start placements, 11m Rule-family placements and 14m Action placements.

There is no single approved grand total for Levels 2 and 3

Users may add more than one Custom Stage in a gap, and no maximum number of Pipelines or Stages has been agreed. Product must first set those limits and publish the per-gap compatibility matrix. Until then, the honest answer is: 3 scope levels, 5 product cases, exact Level 1 counts, per-Stage Level 2 counts and a variable Level 3 total.
