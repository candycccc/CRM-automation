Inside the 12 Templates: fixed structure vs editable values

A Template does not expose a blank workflow. WeQuote supplies the recipe; the user only completes the settings that the selected Template opens.

Same rule for all 12
Template and context
Fixed by WeQuote

Template name, identity and its Qualified, In Progress, In Review, Passed Review, Sent, Won or Lost context.

User can change

Turn an instance on or off and reorder instances only within the same context. These do not edit the recipe.

Starts when
Fixed by WeQuote

The start event and its Quote context. All 12 Template placements are assigned in advance.

User can change

Nothing inside the Template. A different start event requires a different Template or Start from scratch.

Rule and Yes / No paths
Fixed by WeQuote

Whether a Rule exists, its logic and operator, and what happens on each path.

User can change

Only the two threshold values in High-value approval: Quote value and discount percentage.

Wait
Fixed by WeQuote

Whether a Wait exists, where it sits and its order. Two Templates include a Wait; ten do not.

User can change

The number of days only in Qualified inactivity reminder and Sent Quote follow-up.

Action and order
Fixed by WeQuote

The Action type, duplicate handling and internal step order: 10 Create Note, 1 Set Deal Next Action and 1 Create Draft Invoice.

User can change

Approved Action values only: five Next Action fields or six Note fields. Draft Invoice exposes no setting.

How the 63 settings are counted
